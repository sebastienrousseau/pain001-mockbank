# Security

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** facility for this repository, not a public issue:
<https://github.com/sebastienrousseau/pain001-mockbank/security/advisories/new>.
If private reporting is unavailable, contact the maintainer using the email
in `pyproject.toml`. Do not include real payment data or credentials.

This package follows the
[`pain001` security policy](https://github.com/sebastienrousseau/pain001/blob/main/SECURITY.md)
and ships in lockstep with the rest of the pain001 suite. Published
advisories are listed at
<https://github.com/sebastienrousseau/pain001-mockbank/security/advisories>.

This initial development version is a synthetic test fixture, not a production
security boundary. Do not expose listeners publicly. Dependencies are locked
and audited in CI. No response SLA or independent security audit is claimed.
