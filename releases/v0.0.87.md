# pain001-mockbank v0.0.87

## Highlights ⭐️

* **No SHA-1 on the SFTP listener**: SHA-1 key exchange, SHA-1 MACs and `ssh-rsa` signatures are removed for the host key and for client keys. OpenSSH, paramiko and asyncssh clients negotiate SHA-2 as before; a client that offers only SHA-1 is refused.
* **Suite Consistency audits on a schedule only**: it no longer runs on another workflow's completion (`workflow_run`), which ran with the default branch's trust whatever started it, and it pins a core check that knows the five SDK repositories, so the scheduled runs pass again.
* **In lockstep with pain001 0.0.87**: the floor on core moves to 0.0.87, and the lock resolves its published artifacts.

## Details

The README's Security section names the project's OpenSSF Best Practices passing badge. pyproject.toml, `__version__`, CITATION.cff, the README's image tag and stability line move to 0.0.87 together.
