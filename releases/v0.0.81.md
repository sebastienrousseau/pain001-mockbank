# pain001-mockbank v0.0.81

## Highlights ⭐️

* **First tagged release, in lockstep with the suite**: the mock bank takes the suite's version and requires `pain001 >= 0.0.81, < 1`. It accepts pain.001 uploads over authenticated SFTP and answers each with an ACCP, RJCT or PDNG pain.002 built by core pain001, with bounded YAML rejection rules that never evaluate Python.
* **A versioned, signed image you can pin**: each suite tag pushes `ghcr.io/sebastienrousseau/pain001-mockbank:<version>` (amd64 and arm64, with provenance and SBOM, signed by digest, never overwritten) and attaches the signed sdist and wheel. Until now only `edge` moved.
* **Fuzzed parsers**: Atheris holds the upload and rules parsers to their contract, two minutes on every change and thirty weekly, and the test suite replays the seed corpus without Atheris.
* **Supply chain**: Poetry is installed from a hash-pinned tree in the image build, `SECURITY.md` links the private advisory form, and the Dependabot updates (filelock 4.2.9, types-pyyaml, docker/login-action 4.8.0, codeql-action upload-sarif 4.39.3) are folded in.
