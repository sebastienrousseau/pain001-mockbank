# pain001-mockbank v0.0.86

## Highlights ⭐️

* **One status block per payment block**: a pain.002 reply now answers each payment block with one `OrgnlPmtInfAndSts` holding all of its transactions. 0.0.85 wrote one block per transaction, each repeating the block's id.
* **README Quick Start runs in CI**: the test suite generates the host key, starts the server, uploads over SFTP and reads the pain.002, and `examples/upload_and_collect.py` walks through the same flow in process.
* **Every pinned requirement audited**: `make sec` runs pip-audit on each hash-pinned `requirements/*.txt` as well as the `poetry.lock` environment, so the image build, fuzz and docs-lint pins are checked too.
* **In lockstep with pain001 0.0.86**: the replies use core 0.0.86's pain.002 builder, which takes a list of transactions per block.

## Details

`load_rules` checks each rule in one small function per check, which empties `complexity-baseline.json`. pyproject.toml, `__version__`, CITATION.cff, the README's image tag and stability line move to 0.0.86 together.
