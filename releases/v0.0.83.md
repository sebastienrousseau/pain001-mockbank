# pain001-mockbank v0.0.83

## Highlights ⭐️

* **In lockstep with pain001 0.0.83**: the mock bank requires `pain001 >= 0.0.83, < 1` and ships `ghcr.io/sebastienrousseau/pain001-mockbank:0.0.83`.
* **Same replies as 0.0.82**: the pain.002 status reports it builds with the core are unchanged; the core's 0.0.83 work is XML signing and signature verification, which the mock bank does not use.

## Container

Each suite release, from 0.0.81, publishes
`ghcr.io/sebastienrousseau/pain001-mockbank:<version>` for Linux amd64 and
arm64: signed with cosign, with build provenance and an SBOM, and never moved.
Pin a pipeline to a version, or to the digest in the release's `image.txt`.
