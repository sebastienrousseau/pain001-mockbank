# Policies

Python 3.11 is the minimum supported interpreter, as across the pain001
suite. CI checks 3.11, 3.12, 3.13 and 3.14. Raising the floor requires a
maintainer decision and changelog entry in a new iteration. No
operating-system distribution LTS promise is made. Initial versions
start at 0.0.1; releases move one 0.0.1 step at a time.
Output and contract changes are compatibility changes, not formatting cleanup.
