# Policies

Python 3.10 is the minimum supported interpreter. CI checks it alongside
Python 3.14. Raising the floor requires a maintainer decision and changelog
entry in a new iteration. No operating-system distribution LTS promise is
made. Initial versions start at 0.0.1; releases move one 0.0.1 step at a time.
Output and contract changes are compatibility changes, not formatting cleanup.
