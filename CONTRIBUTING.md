# Contributing

Read [DEVELOPMENT.md](DEVELOPMENT.md), run `poetry run make check` and
`poetry run make sec`, and include tests with every behavior change.
Preserve generated files: change their sources and regenerate them.
Use conventional, SSH-signed commits with a Signed-off-by DCO trailer.
Do not modify version numbers or publish tags without a maintainer decision.
Contributions use Apache-2.0 OR MIT. Never commit real payment data or keys.
